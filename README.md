# _Skills_ is the new _libraries_
Some skills I have developed for my workflow with Claude.

## List of skills
- [`paper-submission-prep`](skills/paper-submission-prep/SKILL.md): used to adapt a LaTeX paper to a journal's or conference's template and guidelines when submitting, while keeping maximum control over what Claude edits (every change is cited, discussed and approved first; nothing is committed). Includes notes for Elsevier's `elsarticle` in [`references/elsarticle.md`](skills/paper-submission-prep/references/elsarticle.md).

## Installation
Copy a skill folder (e.g. `skills/paper-submission-prep`) into your project's `.claude/skills/` folder, or copy the whole `skills` folder into `.claude/` if the project has no `skills` folder yet.
